Misiones Estratégicas para Compras Industriales

Los 5 Encargos Críticos de Ingeniería y Compras

Donde las especificaciones técnicas marcan la diferencia entre un sistema que dura 10 años o un desastre en campo.

ENCARGO #1 — PRIORIDAD TÉCNICA CRÍTICA
BOM-01 • Meta: ≤ $1,500 MXN

Bomba Sumergible < 2 Pulgadas (Bajo Caudal 1 a 2 L/min)

El reto técnico número 1 del proyecto. Por favor lee esto antes de cotizar cualquier bomba comercial.

Anatomía del Ademe vs Diámetro Exterior (OD)
Ademe PVC Cédula 40 (2" nominal): ID Real = 52.5 mm
Bomba Comercial común "2 pulgadas" (OD 50-51 mm): Holgura < 1 mm ❌ ¡SE ATORA!
Bomba Requerida Bullet / Lápiz (OD 38 a 45 mm): Holgura 7 a 14 mm ✅ ENTRA FLUIDA
Caudal Óptimo: 1 a 2 L/min

Extrae los 400 L/día en una ventana de 3.3 a 6.6 horas sin provocar abatimiento violento del cono freático ni arrastrar sedimentos finos/limos.

Alimentación: 12V o 24V DC

Tolerancia de caudal hasta 6 L/min. Si supera los 2 L/min, se requiere estrangulamiento o línea de retorno hidráulico calibrada.

ENCARGO #2 BOM-02

Cartuchos Lavables & Spin-Down

Evitar que el usuario gaste comprando cartuchos de celulosa cada 15 días:

  • Pre-filtro Spin-Down con malla de acero inoxidable lavable (40 a 50 micras) y válvula de purga rápida.
  • Cartucho plisado de poliéster lavable reutilizable (5 micras) antes del carbón activado en bloque.
Meta compras: Kit completo ≤ $1,300 MXN
ENCARGO #3 BOM-03

Módulos RO Prearmados (Skid)

No queremos armar mangueras en campo bajo el sol:

  • Tren de Ósmosis Inversa de 100 a 150 GPD montado sobre un chasis compacto.
  • Bomba booster 24V DC pre-cableada.
  • Restrictor calibrado a relación 2:1 (por cada 2 L de uso común, 1 L de agua osmotizada). Conectores Push-Fit rápidos.
Meta compras: Skid prearmado ≤ $2,650 MXN
ENCARGO #4 BOM-04 & 05

Telemetría ESP32 & Válvulas

Automatización IoT a prueba de fallas con componentes industriales:

  • Placas ESP32 DevKit v1 (o ESP32-S3) con Wi-Fi/Bluetooth.
  • Caudalímetros de turbina Hall de 1/2" + Transductores de presión (0-100 PSI).
  • Sondas TDS en línea + Relés de estado sólido (SSR) + 4 electroválvulas solenoides 1/2" NC (12V/24V DC).
Meta compras: Lote electrónico ≤ $1,350 MXN
ENCARGO #5 BOM-11 & BENCHMARK

Convenio NOM-201 & Benchmark

El poder de la maquila para certificación oficial y validación comercial:

  • Convenio con Laboratorio Acreditado EMA: Tarifa por volumen para análisis de potabilidad (coliformes, metales, TDS).
  • Benchmark Industrial: Investigar cuánto cobra un proveedor comercial a la maquila por un skid similar de 400 L/día (rango típico: $45K-$80K MXN).
Meta laboratorio: ≤ $1,350 MXN por análisis

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var FILE_ID = "PEGA_AQUI_EL_ID_DE_TU_GOOGLE_SHEET";
    var file = DriveApp.getFileById(FILE_ID);
    
    // Otorgar permiso de Editor o Lector a Joe
    file.addEditor(data.email);
    
    // Guardar en hoja de bitácora
    var ss = SpreadsheetApp.openById(FILE_ID);
    var sheet = ss.getSheetByName("Bitacora_Joe") || ss.insertSheet("Bitacora_Joe");
    sheet.appendRow([
      new Date(), 
      data.email, 
      JSON.stringify(data.roles), 
      data.paquete, 
      data.gananciaObra, 
      data.recurrenteAnual
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", error: err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
